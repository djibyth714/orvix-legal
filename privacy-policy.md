## 1. Introduction

This Privacy Policy explains how the Orvix IPTV application processes data related to its use.

The Application is an IPTV media player that lets users import their own M3U/M3U8 playlists, configure their own Xtream Codes compatible sources and play the content available from those sources. The Application does not provide any channels, playlists or subscriptions.

In its basic version, the Application works without any mandatory user account and without any central server required for its operation.

Protecting personal data and the security of information stored on the device are design principles of the Application.

## 3. Local operation

In its basic version, the Application stores certain information directly on the user's device.

This information may include:

* the names and addresses of added playlists;
* imported channels and categories;
* favorites;
* watch history and playback progress;
* player preferences;
* cached program guide (EPG) data;
* Application settings.

This data is used to provide the features requested by the user.

The local database is not a centralized storage service. Data on one device is not automatically synchronized with another device.

## 4. IPTV credentials and authentication data

When the user configures a source using Xtream Codes or an equivalent mechanism, the Application may process:

* the server address;
* the username;
* the password;
* the information required for the connection;
* the technical responses of the server.

Secrets are kept in the platform's secure storage whenever technically possible, in particular the Keychain on Apple devices and an equivalent secure mechanism on Android.

On Smart TVs (Samsung Tizen, LG webOS, Hisense VIDAA), the TV platforms offer no such secure storage to apps: sources and credentials are kept in the Application's private storage on the TV and are only sent to the server configured by the user.

Passwords are not stored in plain text in the mobile database and never appear in technical logs.

When the user connects to an external IPTV server, the information needed for this connection is sent to that server. The operator of that server may process this information according to its own practices and legal obligations.

The user should therefore check the reliability of the provider to which they send their credentials.

## 5. Data sent to IPTV providers

To play a channel, import a remote catalog or retrieve a program guide, the Application sometimes needs to communicate with external servers.

These servers may receive technical data such as:

* the connection IP address;
* HTTP or HTTPS requests;
* the URL of the requested resource;
* the credentials needed for authentication, when used;
* the technical information required for the server's response.

This processing is carried out to allow the connection, import and playback of the requested content.

External servers are operated by third parties that are not necessarily controlled by the publisher of the Application. Their privacy policy and data retention periods must be checked directly with these operators.

The Application must not collect such data without a functional need, appropriate information and a valid legal basis.

## 10. Retention and deletion

Data stored locally is kept on the device until it is deleted by the user, replaced, or erased as part of the normal operation of the Application.

Depending on the features actually available, the user can:

* remove a playlist or source;
* clear their history;
* clear the cache;
* delete stored credentials;
* erase local data;
* uninstall the Application.

Removing a source also deletes the associated secrets where provided by the storage architecture.

Uninstalling generally deletes the Application's private data, but some exported files or system-managed backups may remain.

On iOS, the Application's local database may be included in the device's iCloud or computer backup, depending on the user's settings; credentials stored in the Keychain are not transferred to another device. On Android, automatic backup of the Application's data is disabled.

Backup files voluntarily exported by the user from the Application never contain any password or playlist address: after restoring, the user enters their credentials again.

Any data kept by an IPTV provider or other third-party service must be deleted according to that provider's rules and procedures.

## 11. Security

The publisher implements technical and organizational measures proportionate to the risks and characteristics of the Application.

These measures include, where technically applicable:

* protection of communications by HTTPS when the server allows it;
* limiting the data stored;
* no plain-text passwords in logs;
* validation of imported URLs and files;
* error handling without disclosing secrets;
* keeping dependencies up to date;
* deleting data when the user requests it.

No computer system can guarantee absolute security. The user remains responsible for the security of their device and the choice of their external providers.
